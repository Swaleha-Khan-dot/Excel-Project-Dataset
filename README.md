# 📊 Excel Data Analysis & Dashboard Project

Welcome to the **Excel Project Dataset** repository! This project demonstrates key data cleaning, analysis, and visualization techniques in Microsoft Excel, culminating in an interactive dashboard.

---

## 🚀 Key Learnings & Skills Demonstrated

In this project, I applied various Excel features to clean raw data, perform logical operations, summarize datasets, and build visual summaries:

### 1. Data Cleaning & Structuring
* **Find and Replace**: Standardized text entries, removed inconsistencies, and cleaned raw data values.
* **Header Setup & Formatting**: Created clear headers, adjusted text alignment, and applied custom designs/shading for enhanced visual hierarchy and readability.

### 2. Logic & Formulas
* **Nested IF Functions**: Categorized and evaluated multi-level conditional logic.
* **Handling `Value_if_false`**: Handled edge cases and fallbacks within logical statements to ensure seamless data output without errors.

### 3. Data Summarization & Interactive Visualization
* **Pivot Tables**: Summarized large volumes of data to uncover trends and key performance metrics.
* **Interactive Slicers**: Added slicers connected to Pivot Tables to allow seamless dynamic filtering.
* **Charts & Visualizations**: Created customized charts to represent data trends clearly.
* **Interactive Dashboard**: Combined pivot tables, charts, and slicers into a cohesive layout for easy decision-making.

---

## 🛠️ File Structure

* **`Excel Project Dataset.xlsx`**: The primary Excel workbook containing the raw dataset, formulas, pivot tables, and dashboard layout.

---

## 📈 Dashboard Preview & Usage

1. Download or clone the repository to access `Excel Project Dataset.xlsx`.
2. Open the file in Microsoft Excel.
3. Navigate to the **Dashboard** sheet to interact with the slicers and dynamically filter the visual charts.
